Conectar con Google Recomendado

Inicia sesion con tu cuenta de Google para acceder a todo tu Drive (incluidas carpetas privadas) sin API Key ni compartir carpetas. Tu biblioteca, playlists y ajustes se guardan en la nube (Firestore) y se sincronizan entre dispositivos.

El login con Google requiere abrir la app por http(s) (no funciona con file://). Configura Firebase en el codigo para activarlo.

API Key de Google Alternativa

Necesitas una API Key de Google Cloud para acceder a los archivos de tu Drive.

Como obtener una API Key
  1. Ve a Google Cloud Console
  2. Crea un nuevo proyecto o selecciona uno existente
  3. Ve a APIs y servicios > Biblioteca
  4. Busca "Google Drive API" y habilitala
  5. Ve a APIs y servicios > Credenciales
  6. Haz clic en "Crear credenciales" > "Clave de API"
  7. Copia la clave y pegala aqui

Carpeta de Musica

Pega el enlace de tu carpeta compartida. Las subcarpetas se convertiran en playlists.

Asegurate de que la carpeta este compartida como "Cualquier persona con el enlace puede ver"

Carpeta de Miniaturas (Opcional)

Carpeta con imagenes que tengan el mismo nombre que las canciones (ej: "Artista - Cancion.jpg" para "Artista - Cancion.mp3")

Deja vacio si las imagenes estan en la misma carpeta que la musica

Carpeta de Letras (Opcional)

Carpeta con archivos .lrc que tengan el mismo nombre que las canciones (ej: "447. ElyOtto - SugarCrash!.lrc"). Al abrir el HTML con doble clic (file://) el navegador no puede leer la carpeta automaticamente: selecciona aqui tu carpeta LYRICS una vez.

Si sirves el HTML por http:// las letras se cargan solas y no necesitas seleccionar nada.
